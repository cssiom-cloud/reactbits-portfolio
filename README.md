# 🌌 Reactbits Single-Page Portfolio

> 🌐 **Live Website:** [https://cssiom-cloud.github.io/reactbits-portfolio/](https://cssiom-cloud.github.io/reactbits-portfolio/)

An award-winning, high-performance personal portfolio website built with **React 19**, **Tailwind CSS v4**, and **Framer Motion**, inspired by the interaction patterns of [Reactbits](https://reactbits.dev).

---

## ✨ Features & Motion Mechanics

- **🌌 Animated Aurora / Blur Gradient Background:** Multi-harmonic floating glow spheres with deep obsidian palette (`bg-neutral-950`).
- **🔤 Blur Text Reveal:** Cascading letter/word-by-word reveal animating from `filter: blur(12px)` and `opacity: 0` to crisp 60fps typography.
- **🍎 Apple-style Animated Dock:** Wave magnification physics bottom dock calculating cursor proximity using `useMotionValue` and `useSpring`.
- **🔦 Spotlight Cards with 3D Tilt:** Real-time radial cursor tracking flashlight overlay on card surface & borders, combined with 3D spatial perspective tilt.
- **🧲 Magnetic Buttons:** Spring-based dual-layer magnetic cursor attraction physics for high-impact CTAs.

---

## 🛠️ Tech Stack

- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS v4
- **Animation Engine:** Framer Motion
- **Icons:** Lucide React & Custom SVG Brand Icons
